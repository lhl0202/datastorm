 LO QUE SE IMPLEMENTÓ
═══════════════════════

1.  VALIDACIÓN DE AUTENTICACIÓN EN CHECKOUT
   - Si el usuario NO está autenticado:
     * Muestra: " Debes iniciar sesión o crear cuenta para continuar"
     * Abre automáticamente el modal de login/registro
     * Cancela el proceso de compra
   
   - Si el usuario está autenticado:
     * Continúa con el proceso de compra
     * Guarda los datos en MySQL

2.  CONEXIÓN A MYSQL
   - Los pedidos se guardan automáticamente en la BD
   - Se guarda: usuario, productos, total, método de pago, estado
   - Se crea un registro en tabla "usuarios" si es nuevo cliente
   - Se crea un pedido con referencias y seguimiento

 INSTALACIÓN RÁPIDA
═════════════════════

PASO 1: Crear base de datos
────────────────────────────
mysql -u root < sql/datastorm_mysql.sql

O desde phpMyAdmin:
- Abre sql/datastorm_mysql.sql
- Copia el contenido
- Pega en "SQL" en phpMyAdmin
- Ejecuta


PASO 2: Configurar credenciales MySQL
───────────────────────────────────────
Edita estos 2 archivos:

api/guardar-pedido.php (líneas ~22-26):
  define('DB_HOST', 'localhost');   // Tu servidor
  define('DB_USER', 'root');        // Tu usuario MySQL
  define('DB_PASS', '');            // Tu contraseña
  define('DB_NAME', 'datastorm');
  define('DB_PORT', 3306);

api/estado.php (líneas ~8-12):
  define('DB_HOST', 'localhost');
  define('DB_USER', 'root');
  define('DB_PASS', '');
  define('DB_NAME', 'datastorm');
  define('DB_PORT', 3306);


PASO 3: Colocar en servidor web
─────────────────────────────────
XAMPP:   C:\xampp\htdocs\datastorm
WAMP:    C:\wamp64\www\datastorm
Linux:   /var/www/html/datastorm

Accede a: http://localhost/datastorm


PASO 4: Probar
──────────────
1. Abre http://localhost/datastorm
2. Agrega productos al carrito
3. Ve a checkout
4. Intenta pagar SIN estar logueado
   ✓ Debe abrir modal de login
5. Crea una cuenta o inicia sesión
6. Intenta pagar siendo usuario autenticado
   ✓ Debe guardar en MySQL
   ✓ Debe mostrar " Compra realizada"

  TROUBLESHOOTING
═══════════════════

Problema: "No hay conexión a MySQL"
Solución:
  1. Verifica que MySQL está corriendo
  2. Revisa credenciales en api/guardar-pedido.php
  3. Comprueba que base de datos 'datastorm' existe

Problema: "Debes iniciar sesión" incluso autenticado
Solución:
  1. Abre DevTools (F12)
  2. Consola → Escribe getUser()
  3. Verifica que retorna un usuario

Problema: Pedido no se guarda en MySQL
Solución:
  1. Abre DevTools (F12) → Network
  2. Haz la compra
  3. Busca "guardar-pedido.php"
  4. Revisa la respuesta
